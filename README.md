# MigraPro

Тестовое задание: шапка, навигация и hero-блок на WordPress.

## Что внутри

- собственная классическая WordPress-тема без готовых шаблонов;
- адаптивные header и hero из исходной вёрстки;
- навигация через нативное меню WordPress;
- поля hero-блока через Advanced Custom Fields (ACF) с безопасными резервными значениями.

## Локальный запуск

1. Скопируйте папку темы в `wp-content/themes/migrapro`.
2. В админке WordPress откройте **Внешний вид → Темы** и активируйте **MigraPro**.
3. Установите и активируйте бесплатный плагин **Advanced Custom Fields**.
4. Создайте страницу «Главная», назначьте её главной в **Настройки → Чтение** и заполните поля блока **MigraPro: hero-блок**.
5. В **Внешний вид → Меню** создайте меню, назначьте ему область **Основное меню**. Пункт «Услуги» должен быть родительским, а услуги — его дочерними пунктами.
6. Для пункта «Все услуги и цены» включите поле **CSS Classes** в «Настройках экрана» и задайте класс `menu-item--cta`.

## Технологии

PHP, HTML, CSS, JavaScript, WordPress, ACF.
