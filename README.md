# BriefCube

Интерактивный WordPress-проект для сборки краткого брифа на сайт. Пользователь
выбирает параметры проекта, видит их в 3D-сцене и отправляет заявку, которая
сохраняется в админке WordPress.

## Что реализовано

- собственная классическая WordPress-тема без конструкторов;
- 3D-сцена на Three.js, собранная локально через esbuild;
- адаптивный интерфейс и вариант без анимации для `prefers-reduced-motion`;
- ACF-поля для hero-блока с безопасными значениями по умолчанию;
- нативное меню WordPress с понятным fallback-меню;
- форма брифа с nonce-проверкой и сохранением заявок как записей в админке.

## Локальный запуск

1. Откройте сайт LocalWP и активируйте тему **BriefCube** в разделе
   **Внешний вид → Темы**.
2. Установите и активируйте бесплатный плагин **Advanced Custom Fields**,
   если хотите редактировать текст первого экрана из админки.
3. Назначьте страницу «Главная» статической в **Настройки → Чтение**.
4. Для сборки 3D-модуля установите зависимости и выполните:

   ```bash
   npm install
   npm run build
   ```

5. Заявки из формы появляются в левом меню админки в разделе **Брифы**.

## Разработка

Исходник 3D-сцены находится в `src/briefcube-scene.js`. В репозиторий
коммитится исходный код и lock-файл; собранный файл `assets/js/briefcube-scene.js`
генерируется командой `npm run build`.
